# Разработка веб-сайта проекта «Jerry Spiced»

## Введение и цели работы
- Jerry Spiced - игра жанра кликер с элементами крафта и развития. Проект отличается уникальным визуальным стилем, продуманной системой прогрессии и удобным пользовательским интерфейсом. При разработке были учтены наиболее распространённые недостатки игр данного жанра, такие как медленный старт, однообразный игровой процесс и отсутствие ощущения развития персонажа. Особое внимание уделяется тому, чтобы игрок постоянно видел результаты своих действий и ощущал прогресс на каждом этапе прохождения.
- Цель проекта — разработка увлекательной мобильной игры с системой прогресса, улучшений и создания новых предметов.


## Организация совместной работы и версионирование
Для организации совместной работы и хранения материалов проекта был создан репозиторий на GitHub. В репозитории размещены исходные файлы сайта, документация проекта и другие материалы, связанные с разработкой Jerry Spiced. Использование системы контроля версий Git позволило отслеживать изменения, сохранять историю разработки и обеспечивать удобную работу с файлами проекта.

## Технологический стек и реализация сайта
В качестве инструмента для реализации веб-сайта был выбран генератор статических сайтов Hugo. 
Данный выбор обусловлен следующими преимуществами:
- Высокая скорость генерации страниц и рендеринга на стороне клиента.
- Гибкая система шаблонов, позволяющая эффективно управлять структурой проекта.
- Простота процесса публикации и хостинга статических файлов.

### Настройка среды разработки:
Было подготовлено рабочее окружение, включающее установку самого генератора Hugo и необходимых зависимостей. Проведена инициализация нового сайта и конфигурация базовых параметров через файл config.toml.

### Создание структуры и подключение темы:
Для придания сайту современного вида и сокращения времени на верстку была подключена готовая тема оформления. Структура каталогов проекта была спроектирована в соответствии со стандартами Hugo, включая разделение на разделы для контента, статических ресурсов (изображений, шрифтов) и переиспользуемых компонентов.

### Разработка информационных разделов сайта:
На основе подготовленных материалов были созданы и наполнены ключевые страницы сайта:

#### Главная страница (Home) 
Содержит краткую аннотацию проекта "Jerry Spiced", вводящую пользователя в контекст и описывающую основную идею будущей игры-кликера.
#### Страница описания проекта (About) 
Предоставляет более детальную информацию о целях, механиках и планах по реализации игрового продукта.
#### Раздел участников (Team) 
Включает список членов команды, их роли и зоны ответственности в рамках данного проекта.
#### Журнал разработки (Development Log / Changelog) 
Динамически обновляемый раздел, который служит для фиксации ключевых этапов, достигнутых целей и будущих планов. Это позволяет отслеживать прогресс проекта во времени.
#### Страница полезных ресурсов (Resources) 
Агрегатор ссылок на внешние инструменты, библиотеки, документацию и статьи, которые использовались или могут быть полезны другим разработчикам, заинтересованным в проекте.
## Заключение
В ходе выполнения практической работы была успешно создана инфраструктура для поддержки проекта "Jerry Spiced". Разработанный сайт является не только публичной визиткой, но и внутренним инструментом управления знаниями. Использование платформы GitHub и генератора Hugo заложило прочный фундамент для дальнейшей разработки сайта.
