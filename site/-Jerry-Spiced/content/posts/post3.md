# Что было сделано
Для организации совместной работы и хранения материалов проекта был создан репозиторий на GitHub. В репозитории размещены исходные файлы сайта, документация проекта и другие материалы, связанные с разработкой Jerry Spiced. Использование системы контроля версий Git позволило отслеживать изменения, сохранять историю разработки и обеспечивать удобную работу с файлами проекта. Репозиторий также используется для резервного хранения данных и дальнейшего развития сайта и документации.

В рамках данной практики был разработан сайт с описанием проекта Jerry Spiced,в нем указаны участники проекта и краткое описание для релязации кликера.Для реализации сайта был выбран генератор статических сайтов Hugo, который позволяет удобно организовать структуру проекта и публиковать материалы в формате веб-страниц.
В процессе работы была выполнена настройка среды разработки, создана структура сайта и подключена тема оформления. Также были подготовлены основные разделы сайта: главная страница с аннотацией проекта, страница с описанием проекта, раздел участников, журнал разработки и страница полезных ресурсов.
Для наполнения сайта использовался язык разметки Markdown, что позволило быстро создавать и редактировать контент.
