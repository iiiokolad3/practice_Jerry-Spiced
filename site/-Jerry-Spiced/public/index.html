Кликер-Крафтер

Кликер-Крафтер — мобильная игра для Android, сочетающая механики кликера, добычи ресурсов и крафта предметов.

Цель проекта — разработка увлекательной мобильной игры с системой прогрессии, улучшений и создания новых предметов.

Аннотация

Jerry Spiced игра жанра кликер с элементами крафта и развития. Проект отличается уникальным визуальным стилем, продуманной системой прогрессии и удобным пользовательским интерфейсом. При разработке были учтены наиболее распространённые недостатки игр данного жанра, такие как медленный старт, однообразный игровой процесс и отсутствие ощущения развития персонажа. Особое внимание уделяется тому, чтобы игрок постоянно видел результаты своих действий и ощущал прогресс на каждом этапе прохождения.

Основные возможности

  • добыча ресурсов;
  • создание предметов;
  • улучшение инструментов;
  • система прогрессии

Создание сайта проекта

Anna Опубликовано 2026-06-04

Что было сделано

Для организации совместной работы и хранения материалов проекта был создан репозиторий на GitHub. В репозитории размещены исходные файлы сайта, документация проекта и другие материалы, связанные с разработкой Jerry Spiced. Использование системы контроля версий Git позволило отслеживать изменения, сохранять историю разработки и обеспечивать удобную работу с файлами проекта. Репозиторий также используется для резервного хранения данных и дальнейшего развития сайта и документации.

В рамках данной практики был разработан сайт с описанием проекта Jerry Spiced,в нем указаны участники проекта и краткое описание для релязации кликера.Для реализации сайта был выбран генератор статических сайтов Hugo, который позволяет удобно организовать структуру проекта и публиковать материалы в формате веб-страниц. В процессе работы была выполнена настройка среды разработки, создана структура сайта и подключена тема оформления. Также были подготовлены основные разделы сайта: главная страница с аннотацией проекта, страница с описанием проекта, раздел участников, журнал разработки и страница полезных ресурсов. Для наполнения сайта использовался язык разметки Markdown, что позволило быстро создавать и редактировать контент.

Проектирование интерфейса

Для нас было важно создать итересный и запоменающийся интерфейс. По этому мы подобрали примерный интерфейс и модельки ресурсов которые будут реализованы в последующих экранизациях нашего проекта. В рамках данного этапа работы было начато проектирование пользовательского интерфейса мобильной игры Jerry Spiced. Основной задачей стало создание удобного и понятного взаимодействия игрока с игровыми механиками. При разработке интерфейса учитывались особенности мобильных устройств, включая ограниченный размер экрана и необходимость быстрого доступа к основным функциям игры.
