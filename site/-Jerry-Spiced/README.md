# Jerry-Spiced

Сайт был разработан с помощью Hugo и выбранной темы оформления для создания удобного и современного интерфейса.

Основной целью создания сайта является презентация проекта Jerry Spiced, а также изучение технологий Markdown, Git и Hugo.

# Создание страниц

Для создания страниц сайта использовались файлы с расширением **.md**. В данных файлах размещалось содержимое страниц, включая текстовую информацию, изображения, ссылки и другие материалы.

Для организации навигации между страницами использовался файл **hugo.toml**, в котором были настроены основные параметры сайта, меню и тема оформления.

# Структура сайта

На сайте были созданы следующие разделы:

- Главная страница с краткой аннотацией проекта
- Страница «О проекте» с подробным описанием проекта Jerry Spiced
- Страница «Участники» с информацией о членах команды и их вкладе в разработку
- Раздел «Журнал», содержащий записи о ходе выполнения проекта
- Страница «Ресурсы» с полезными ссылками на материалы, использованные при разработке

# Использование Markdown

Для наполнения сайта использовался язык разметки Markdown. Его применение позволило быстро создавать и редактировать содержимое страниц без необходимости написания большого количества HTML-кода.

С помощью Markdown были оформлены:

- заголовки и подзаголовки
- списки
- таблицы
- ссылки
- текстовые блоки документации

# Работа с изображениями

Для улучшения визуального оформления сайта были добавлены изображения, схемы и иллюстрации, связанные с проектом. Все графические материалы размещались в папке **static/images**, после чего подключались к страницам с помощью Markdown и HTML.
